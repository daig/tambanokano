# guidelines for working in this repo (expanding as we think of them)

- NEVER edit this file. I will do so manually. you can suggest edits but do not touch it.

- never attempt to estimate the real implementation time cost of speculative / planned work. eg "this will take a half day's work". you're systematically completely wrong (always severely overestimating) so it's a useless attempt. instead, think clearly and honestly about what the work entails and how fragile it might be to get right.
